# Hamza-isp

Sajjeel Labs QHSE landing page — Next.js 16, Tailwind CSS v4, shadcn/ui primitives.

## Run locally

```bash
pnpm install
pnpm dev
```

Requires Node 22 (see `.nvmrc`).

- Design system: `DESIGN.md` and `tokens.css`
- Page copy: `content/landing.ts`
- Section layout variants: `lib/sections.ts` (prototype switchers; hide with `NEXT_PUBLIC_PROTOTYPE_CONTROLS=false`)
